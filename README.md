# Ghost in the Shell — Hackathon Solution

Репозиторий команды **Ghost in the Shell** для хакатона.

## Описание проекта
Проект предназначен для обработки и анализа графа финансовых транзакций (KZT). Программа анализирует цепочки переводов, рассчитывает глубину связей между отправителями и получателями, а также агрегирует объемы средств.

## Структура данных
Файл `data` содержит структурированный граф транзакций (Parquet / Arrow):
- `src` — ID отправителя
- `dst` — ID получателя
- `sum_kzt` — сумма транзакции в тенге
- `n_tx` — количество транзакций
- `depth` — глубина связи в графе
- `is_seed` — маркер начального узла
- `gid` — ID группы/графа
